# MyBillPilot

Your bill-pay assistant: track every bill, approve each payment, and keep kids' allowances in one place.
Part of the CashCow app family.

- React + Vite, all files at the top level (no folders needed).
- Data is saved on the user's device only (no accounts, no server copy).
- Payment pages are checked by ScamShield before the user pays.

## Run locally
```
npm install
npm run dev
```
